Temperature Converter in Python

Overview

Temperature Converter is a menu-driven Python project that converts temperatures between Celsius, Fahrenheit and Kelvin. It demonstrates functions, conditional statements, modules, input validation, exception handling and basic testing.


Features


Celsius to Fahrenheit and Kelvin

Fahrenheit to Celsius and Kelvin

Kelvin to Celsius and Fahrenheit

Same-unit conversion

Input validation

Error handling

Conversion history

Automated validation tests


Technologies


Python 3

VS Code / IDLE / any Python IDE

Git and GitHub


Project Structure


main.py - user interface and main workflow

converter.py - conversion logic

validation.py - input validation

history.py - conversion history

test_converter.py - tests

statement.md - project statement


How to Run


Install Python 3.

Open the project folder in VS Code.

Run: python main.py


How to Test

Run:
python test_converter.py


Sample

Input: 100 C to F
Output: 212.00 °F
